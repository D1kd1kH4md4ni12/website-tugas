Penjelasan Algoritma

FCFS (First Come First Serve)

Melayani request sesuai urutan kedatangan. Sederhana tetapi tidak efisien karena head bergerak acak mengikuti urutan permintaan.

SSTF (Shortest Seek Time First)

Selalu memilih request terdekat dari posisi head saat ini. Paling optimal dalam mengurangi seek time tetapi berpotensi menyebabkan starvation.
