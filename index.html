Analisis Kebutuhan Sistem

Deskripsi: Menganalisis kebutuhan sistem untuk aplikasi manajemen tugas kampus.

Tanggal Pengumpulan: 15 Oktober 2023

Status: Selesai

Detail: Dalam tugas ini, saya melakukan analisis kebutuhan fungsional dan non-fungsional untuk aplikasi manajemen tugas kampus. Aplikasi ini akan membantu mahasiswa dalam mengorganisir tugas-tugas mereka dengan fitur reminder, klasifikasi mata kuliah, dan prioritas tugas.

Diagram UML

Deskripsi: Membuat diagram use case, class diagram, dan sequence diagram.

Tanggal Pengumpulan: 30 Oktober 2023

Status: Selesai

Detail: Tugas ini mengharuskan pembuatan tiga jenis diagram UML untuk sistem manajemen tugas kampus. Use case diagram menggambarkan interaksi antara aktor dan sistem, class diagram menunjukkan struktur kelas, dan sequence diagram menampilkan alur interaksi antar objek.
